\textbf{Цель работы:}
Приобретение практических навыков установки, конфигурирования и администрирования реляционной СУБД Microsoft SQL Server Express и графической среды разработки SQL Server Management Studio.
Создание физической базы данных издательской компании с использованием декларативных команд языка T-SQL, проведение теоретического и практического нормализационного анализа отношений базы данных с обоснованием их соответствия требованиям первой, второй и третьей нормальных форм.

\textbf{Постановка задачи:}

\begin{enumerate}
    \item Выполнить установку и базовую настройку СУБД Microsoft SQL Server Express и клиентского приложения SSMS\@.
    \item Реализовать физическую структуру базы данных pub\_house\_db, включающую 10 таблиц, первичные ключи, внешние ключи с правилами поддержания целостности, а также доменные ограничения на значения полей.
    \item Провести нормализацию отношений и доказать, что спроектированная схема базы данных удовлетворяет всем критериям третьей нормальной формы:
    \begin{itemize}
        \item 1NF: обеспечить атомарность данных в каждой ячейке, типизацию столбцов и отсутствие списков/массивов значений;
        \item 2NF: устранить частичные функциональные зависимости неключевых атрибутов от составных первичных ключей путём корректной декомпозиции отношений;
        \item 3NF: исключить транзитивные функциональные зависимости неключевых атрибутов от других неключевых столбцов за счёт выделения независимых таблиц.
    \end{itemize}
    \item Предоставить полный листинг SQL-команд создания базы данных и скриншоты.
\end{enumerate}
