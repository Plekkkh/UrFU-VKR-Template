\textbf{Цель работы:} Изучить характеристики производственных пылей, их воздействие на организм человека, освоить количественные методики расчета риска профессионального заболевания пневмокониозом.

Исходные данные (вариант 17):
\begin{itemize}
    \item Вид пыли --- № 1: породная, углепородная пыль (SiO$_2$ 10--70~\%), ПДК $= 2$ мг/м$^3$;
    \item число рабочих дней в году $N = 247$;
    \item количество лет контакта с АПФД $T = 30$ лет;
    \item возраст рабочего $X_1 = 50$ лет;
    \item общий стаж работы $X_2 = 32$ года;
    \item периоды работы: $t_1 = 10$ лет, $t_2 = 10$ лет, $t_3 = 5$ лет, $t_4 = 5$ лет;
    \item категория тяжести работ --- III\@.
    \item среднесменные концентрации пыли: $K_1 = 5$, $K_2 = 4$, $K_3 = 6$, $K_4 = 5$~мг/м$^3$;
\end{itemize}
