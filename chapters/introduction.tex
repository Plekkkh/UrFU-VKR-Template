\centeredheading{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

\textbf{Цель работы:} Изучение базовых концепций реляционной модели данных, проведение анализа предметной области «Издательская деятельность», построение концептуальной и логической моделей данных в нотации Мартина «Воронья лапка», определение ключевых атрибутов, структур таблиц, связей и доменных ограничений целостности.

\textbf{Постановка задачи:} Спроектировать базу данных компании, занимающейся издательской деятельностью, предназначенную для информационного обслуживания менеджеров, редакторов и руководства.
Система должна учитывать следующие особенности предметной области:

\begin{enumerate}
    \item Каждая книга издаётся в рамках контракта.
    \item Книга может быть написана несколькими авторами.
    \item Контракт подписывается между одним менеджером компании и всеми авторами книги.
    \item Каждый автор может написать несколько книг (по разным контрактам).
    \item Порядок, в котором авторы указаны на обложке книги, влияет на размер их гонорара.
    \item Если сотрудник является редактором, то он может работать одновременно над несколькими книгами.
    \item У каждой книги может быть несколько редакторов, при этом один из них является ответственным редактором.
    \item Каждый заказ оформляется на одного заказчика.
    \item В одном заказе на покупку может быть перечислено несколько книг.
\end{enumerate}
