\centeredheading{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

\textbf{Цель работы:} Освоить методику разработки проекта нормативов предельно допустимых выбросов, загрязняющих веществ в атмосферу для стационарного источника выброса, рассчитать приземные концентрации вредных веществ при неблагоприятных метеорологических условиях, сопоставить их с гигиеническими нормативами на границе санитарно-защитной зоны и установить нормативы ПДВ.

Исходные данные (вариант 17):
\begin{itemize}
    \item количество рабочих дней в году — 255;
    \item продолжительность односменной работы — 8~ч;
    \item высота источника выброса $H = 12{,}5$~м;
    \item коэффициент температурной стратификации атмосферы $A = 160$;
    \item коэффициент, учитывающий скорость оседания вредных веществ, $F = 1{,}0$;
    \item коэффициент, учитывающий условия выхода газовоздушной смеси из устья источника, $n = 1{,}49$;
    \item коэффициент, учитывающий влияние рельефа местности, $\eta = 1{,}0$;
    \item коэффициент, зависящий от скорости выхода газовоздушной смеси, $K = 0{,}016$;
    \item скорость выхода газовоздушной смеси $\omega_0 = 14{,}1$~м/с;
    \item диаметр устья трубы $D = 0{,}71$~м;
    \item размер санитарно-защитной зоны $X = 500$~м.
\end{itemize}
