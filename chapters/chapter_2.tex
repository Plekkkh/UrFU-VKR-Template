\section{Исследование алгоритма XOR (Test AKA)}

В программе «2G + 3G Authentication» установлен режим работы XOR (Test AKA).
Структура поля $\mathrm{AUTN}$, состоящего из 32 hex-символов, имеет следующую структуру:
\begin{equation*}
    \mathrm{AUTN} = \underbrace{\textcolor{sqnakcolor}{\mathrm{SQN} \oplus \mathrm{AK}}}_{\text{12 hex-символов}} \;\parallel\;
    \underbrace{\textcolor{amfcolor}{\mathrm{AMF}}}_{\text{4 hex-символа}} \;\parallel\;
    \underbrace{\textcolor{maccolor}{\mathrm{MAC-A}}}_{\text{16 hex-символов}}.
\end{equation*}

\subsection{Влияние параметра SQN}\label{subsec:param-sqn}

Исходные данные:
\begin{itemize}
    \item $\mathrm{RAND} = \mathrm{0xFF \dots FF}$
    \item $\mathrm{AMF} = \mathrm{0xFFFF}$
    \item Res Length = 16
    \item $\mathrm{MCC} = 250$
    \item $\mathrm{MNC} = 17$
\end{itemize}

Параметры, зависящие от $\mathrm{SQN}$, выделены шрифтом.
