\chapter{Анализ результатов}

Расчет приземных концентраций показал, что при наиболее неблагоприятных метеорологических условиях для шести веществ варианта (оксид углерода, диоксид серы, сульфат натрия, толуол, поташ, азотная кислота) как максимальные приземные концентрации $C_{\text{м}}$, так и концентрации $C$ на границе санитарно-защитной зоны 500~м не превышают соответствующих ПДК$_{\text{м.р.}}$, и нормативы ПДВ устанавливаются на уровне фактических выбросов.

Для четырех веществ (соли никеля, стирол, медь и фенол) максимальные приземные концентрации $C_{\text{м}}$ превышают ПДК, а на границе СЗЗ концентрации $C$ превышают ПДК в $k = 2{,}7$--$4{,}6$ раза.
Для этих веществ фактический выброс принимается как временно согласованный выброс (ВСВ), а норматив ПДВ определяется по формуле $\text{ПДВ} = M_i / k$: соли никеля — 0,245 т/год; стирол — 4,90 т/год; медь — 0,37 т/год; фенол — 1,22 т/год.

Рекомендации:
\begin{itemize}
    \item утвердить нормативы ПДВ (для шести веществ — на уровне фактических выбросов, для четырех — по расчету $M_i/k$) и ВСВ на уровне фактических выбросов (табл.~\ref{tab:pdv});
    \item для солей никеля, стирола, меди и фенола разработать план мероприятий по достижению нормативов ПДВ: повышение эффективности газоочистного оборудования, изменение технологии и сырья, увеличение высоты выброса;
    \item организовать регулярный производственный экологический контроль, поскольку соли никеля и медь --- вещества 1--2 классов опасности с малыми ПДК;
    \item при увеличении объемов производства или изменении технологии пересчитать нормативы ПДВ;
    \item при особо неблагоприятных метеорологических условиях предусмотреть режим снижения выбросов в соответствии с требованиями природоохранного законодательства.
\end{itemize}
