Хостовая машина (Windows) / VMware Workstation &
Настройки ВМ \texttt{Preloader} (Shared Folders) &
Открыть свойства ВМ \texttt{Preloader}, перейти на вкладку Options -- Shared Folders, выбрать Always enabled, нажать Add\ldots и подключить общую папку хоста для обмена файлами с ВМ. &
Общий каталог хоста, доступный в ВМ по пути \texttt{/mnt/\allowbreak hgfs}. \\
\hline

Preloader (Debian 10) &
Терминал ОС (файловая система и эмулятор QEMU/OVMF) &
Войти под учетной записью \texttt{root}. При необходимости смонтировать общую папку. Создать каталог \texttt{test-uefi} и подкаталог \texttt{hd-contents}, скопировать образ прошивки OVMF (\texttt{bios.bin}) и приложение \texttt{HelloWorld.efi}. Запустить эмуляцию UEFI в QEMU. &
Учетные данные: \texttt{root} / \texttt{P@ssw0rd}\par
\vspace{4pt}
Команды:\par
\texttt{mount /mnt/hgfs}\par
\texttt{mkdir -p \textasciitilde{}/test-uefi/\allowbreak hd-contents}\par
\texttt{cp /usr/\allowbreak share/\allowbreak ovmf/\allowbreak OVMF.fd \textasciitilde{}/test-uefi/\allowbreak bios.bin}\par
\texttt{cp /usr/\allowbreak src/\allowbreak edk2/\allowbreak Build/\allowbreak MdeModule/\allowbreak DEBUG\_GCC5/\allowbreak X64/\allowbreak HelloWorld.efi \textasciitilde{}/test-uefi/\allowbreak hd-contents/}\par
\texttt{cd \textasciitilde{}/test-uefi}\par
\texttt{qemu-system-x86\_64 -pflash bios.bin -net none -hda fat:rw:hd-contents} \\
\hline


Хостовая машина (Windows) &
Windows PowerShell (командлеты PKI: \texttt{New-\allowbreak SelfSigned\allowbreak Certificate}, \texttt{Export-\allowbreak Certificate}, \texttt{Export-\allowbreak PfxCertificate}) &
Создать рабочий каталог для ключевой информации (\texttt{lab1-uefi\_keys}). Сгенерировать самоподписанный корневой сертификат Platform Key (\texttt{Test\_PK}), затем выпустить и подписать им сертификат подписи кода Key Exchange Key (\texttt{Test\_KEK}). Экспортировать оба сертификата в DER-формат (\texttt{.cer}) для импорта в UEFI и экспортировать \texttt{Test\_KEK} с закрытым ключом в контейнер \texttt{.pfx}. (Использован PowerShell вместо устаревшей утилиты \texttt{makecert.exe}.) &
Пароль: \texttt{P@ssw0rd}\par
\vspace{4pt}
\texttt{\$pwd = ConvertTo-SecureString -String "P@ssw0rd" -Force -AsPlainText}\par
\vspace{3pt}
\texttt{\$pk = New-\allowbreak SelfSigned\allowbreak Certificate -Subject "CN=Test\_PK" -Type Custom -KeySpec Signature -KeyAlgorithm RSA -KeyLength 2048 -HashAlgorithm SHA256 -KeyUsage CertSign, CRLSign, DigitalSignature -TextExtension @("2.5.29.19=\allowbreak\{critical\}\allowbreak\{text\}ca=true") -KeyExportPolicy Exportable -CertStoreLocation "Cert:\textbackslash{}CurrentUser\textbackslash{}My"}\par
\vspace{3pt}
\texttt{\$kek = New-\allowbreak SelfSigned\allowbreak Certificate -Subject "CN=Test\_KEK" -Type CodeSigningCert -Signer \$pk -KeySpec Signature -KeyAlgorithm RSA -KeyLength 2048 -HashAlgorithm SHA256 -KeyExportPolicy Exportable -CertStoreLocation "Cert:\textbackslash{}CurrentUser\textbackslash{}My"}\par
\vspace{3pt}
\texttt{Export-Certificate -Cert \$pk -FilePath ".\textbackslash{}TestPK.cer" -Type CERT}\par
\texttt{Export-Certificate -Cert \$kek -FilePath ".\textbackslash{}TestKEK.cer" -Type CERT}\par
\texttt{Export-PfxCertificate -Cert \$kek -FilePath ".\textbackslash{}TestKEK.pfx" -Password \$pwd}\par
\vspace{3pt}
Файлы: \texttt{TestPK.cer}, \texttt{TestKEK.cer}, \texttt{TestKEK.pfx}. \\
\hline

Preloader (Debian 10) &
Файловая система ВМ &
При остановленной эмуляции QEMU скопировать файлы сертификатов \texttt{TestPK.cer} и \texttt{TestKEK.cer} из общей папки в каталог виртуального диска \texttt{\textasciitilde{}/test-uefi/hd-contents/}. &
Команда:\par
\texttt{cp /mnt/\allowbreak hgfs/\allowbreak shared/\allowbreak lab1-uefi\_keys/\allowbreak *.cer \textasciitilde{}/test-uefi/\allowbreak hd-contents/} \\
\hline

Preloader (эмуляция UEFI в QEMU) &
Утилита настройки UEFI (OVMF Setup -- Secure Boot Configuration) &
Выйти из UEFI Shell командой \texttt{exit}. Перейти в Device Manager -- Secure Boot Configuration. Перевести Secure Boot Mode в Custom Mode и открыть Custom Secure Boot Options. Последовательно в пунктах PK Options и KEK Options выбрать Enroll \ldots -- Enroll \ldots Using File, указать соответствующие \texttt{.cer}-файлы и сохранить изменения (Commit Changes and Exit). Перезагрузить эмуляцию. &
Импортируемые файлы:\par
PK Options: \texttt{TestPK.cer}\par
KEK Options: \texttt{TestKEK.cer} \\
\hline

Хостовая машина (Windows) &
PowerShell / утилита \texttt{signtool.exe} (Microsoft Windows SDK) &
Скопировать \texttt{HelloWorld.efi} в каталог с ключами. Подписать файл сертификатом \texttt{Test\_KEK} с указанием SHA-1 отпечатка сертификата (так как контейнер \texttt{.pfx} содержит цепочку сертификатов) и алгоритмом хэширования \texttt{sha256}. Скопировать подписанный файл \texttt{HelloWorld.efi} обратно в каталог \texttt{\textasciitilde{}/test-uefi/hd-contents/} на ВМ \texttt{Preloader}. &
Команда:\par
\texttt{.\textbackslash{}signtool.exe sign /ac .\textbackslash{}TestKEK.cer /f .\textbackslash{}TestKEK.pfx /p P@ssw0rd /sha1 \seqsplit{F3C8F724B7C93BD11167370E110C671120E1D7C7} /fd sha256 .\textbackslash{}HelloWorld.efi} \\ % chktex 26
\hline

Preloader (эмуляция UEFI в QEMU) &
Утилита настройки UEFI (Custom Secure Boot Options -- DB Options) &
Вариант А: перейти в Device Manager -- Secure Boot Configuration -- Custom Secure Boot Options -- DB Options -- Enroll Signature -- Enroll Signature Using File, выбрать \texttt{TestKEK.cer}, сохранить и перезагрузить эмуляцию.\par
\vspace{4pt}
Вариант Б: удалить запись \texttt{TestKEK.cer} из DB Options (Delete Signature), добавить сигнатуру самого приложения \texttt{HelloWorld.efi} (Enroll Signature Using File -- \texttt{HelloWorld.efi}), сохранить и перезагрузить эмуляцию. &
Разрешенные сигнатуры (переменная \texttt{db}):\par
Вариант А: \texttt{TestKEK.cer}\par
Вариант Б: \texttt{HelloWorld.efi} \\
\hline

Хостовая машина (Windows) &
HEX-редактор HxD &
Открыть подписанный файл \texttt{HelloWorld.efi} в редакторе HxD. Найти строку \texttt{UEFI Hello World!} в кодировке UTF-16, изменить слово \texttt{UEFI} с сохранением длины строки, сохранить файл и скопировать его в \texttt{\textasciitilde{}/test-uefi/hd-contents/} на ВМ \texttt{Preloader}. &
Изменение строки (UTF-16LE):\par
Было: \texttt{UEFI Hello World!}\par
Стало: \texttt{BIOS Hello World!} \\
\hline

Preloader (эмуляция UEFI в QEMU) &
Утилита настройки UEFI (Secure Boot Configuration) &
Открыть настройки UEFI, перейти в Device Manager -- Secure Boot Configuration, снять флаг опции Attempt Secure Boot, сохранить изменения и перезагрузить эмуляцию. &
Параметр Attempt Secure Boot: отключен (\texttt{[ ]}). \\
\hline

\hline
\endfirsthead

\hline
Описание проверки & Ожидаемый результат \\
\hline
\endhead

\hline
\endfoot

1. В базовой конфигурации (до активации Secure Boot) перейти на раздел \texttt{fs0:}, просмотреть содержимое (\texttt{dir}) и запустить неподписанное приложение \texttt{HelloWorld.efi}. &
Приложение успешно запускается и выводит строку \texttt{UEFI Hello World!}. \\
\hline

2. В UEFI Shell проверить значение переменной \texttt{SetupMode} командой \texttt{setvar SetupMode} до установки ключа PK. &
Переменная \texttt{SetupMode} имеет значение \texttt{01} (система находится в режиме настройки -- Setup Mode). \\
\hline

3. После импорта ключей PK и KEK и перезагрузки проверить переменную \texttt{SetupMode} и попытаться запустить неподписанный файл \texttt{HelloWorld.efi}. &
Переменная \texttt{SetupMode} имеет значение \texttt{00} (User Mode). Запуск заблокирован, выводится сообщение \texttt{Command Error Status: Security Violation}. \\
\hline

4. На хостовой машине Windows открыть свойства подписанного файла \texttt{HelloWorld.efi} на вкладке «Цифровые подписи». &
В списке отображается цифровая подпись от имени \texttt{Test\_KEK} с алгоритмом хэширования \texttt{sha256}. \\
\hline

5. Попытаться запустить подписанный файл \texttt{HelloWorld.efi} в UEFI Shell при пустой базе разрешенных сигнатур (\texttt{db}). &
Запуск заблокирован, выводится сообщение \texttt{Command Error Status: Security Violation}. \\
\hline

6. Добавить сертификат \texttt{TestKEK.cer} в DB Options, перезагрузить эмуляцию и запустить подписанный файл \texttt{HelloWorld.efi}. &
Приложение успешно проходит проверку подписи и выводит строку \texttt{UEFI Hello World!}. \\
\hline

7. Удалить \texttt{TestKEK.cer} из DB Options, добавить в DB Options сигнатуру файла \texttt{HelloWorld.efi}, перезагрузить эмуляцию и запустить \texttt{HelloWorld.efi}. &
Приложение успешно запускается и выводит строку \texttt{UEFI Hello World!}. \\
\hline

8. Модифицировать подписанный файл \texttt{HelloWorld.efi} в редакторе HxD, скопировать его в \texttt{hd-contents} и попытаться запустить при включенном Secure Boot. &
Запуск модифицированного файла заблокирован, выводится сообщение \texttt{Command Error Status: Security Violation}. \\
\hline

9. Отключить опцию Attempt Secure Boot в настройках UEFI, перезагрузить эмуляцию и запустить модифицированный файл \texttt{HelloWorld.efi}. &
Приложение успешно запускается и выводит измененную строку приветствия. \\
\hline
\end{tabularx}
\endgroup
