\centeredheading{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

В ходе выполнения лабораторной работы была спроектирована и программно реализована комплексная подсистема защиты и мониторинга безопасности базы данных издательской компании \code{pub\_house\_db} в среде СУБД Microsoft SQL Server Express. 
Перевод сервера в смешанный режим проверки подлинности позволил задействовать встроенные механизмы парольной аутентификации SQL Server с поддержкой системных политик сложности и блокировки учетных записей.

В рамках реализации контроля доступа были сформированы сценарии работы для двух категорий субъектов --- администраторов базы данных и аутентифицированных пользователей.
Создание двух учетных записей администраторов и двух учетных записей сотрудников (менеджера и редактора) с последующим распределением прав через ролевую модель позволило строго изолировать контуры доступа к данным.
Проведенное функциональное тестирование подтвердило соблюдение принципа наименьших привилегий: каждая учетная запись беспрепятственно выполняет свои должностные операции, в то время как любые попытки обращения к неразрешенным таблицам или изменения структуры базы данных пресекаются ядром СУБД.

На втором этапе работы с использованием встроенных промышленных инструментов СУБД --- подсистемы SQL Server Audit, динамических административных представлений и монитора активности --- был организован непрерывный мониторинг безопасности базы данных.
Настроенные спецификации серверного и объектного аудита обеспечили надежную регистрацию всех попыток аутентификации, изменений привилегий и обращений к защищаемым объектам.
Проведенные испытания по имитации несанкционированных запросов и серии многократных неудачных входов пользователя продемонстрировали высокую эффективность разработанных аналитических запросов детектирования, позволивших оперативно выявить признаки подбора пароля и попытки превышения полномочий по данным защищенных журналов аудита.
